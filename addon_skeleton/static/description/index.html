Addon Skeleton

A clean starting point for your own Odoo module, with every building block in place.

Model

A model with sequence number, customer, responsible user, status and chatter.

Security

User and administrator groups, access rights with record domains, portal access limited to the own company.

Views

List, form and search views, action, menu with app icon and a portal page.

Data and Static

Sequence and portal card as XML data, SCSS in the backend asset bundle, icon and cover.
